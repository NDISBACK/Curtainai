The problem

AI agents are shipping to production.
Governance isn't.

No oversight layer

Agents take irreversible actions — sending emails, processing refunds, modifying records — with zero human checkpoint.

No audit trail

When something goes wrong, there's no record of why the agent decided what it did. Debugging is impossible. Compliance is a nightmare.

No policy layer

Guardrails are hardcoded in prompts. They drift, hallucinate, and can't scale across hundreds of agent actions or team members.

Real incident, beta prospect: "Our agent sent $14,000 in refunds to the wrong customer segment. We had no logs, no rollback, and no idea which prompt change caused it."

The solution

One layer between your agent and the world.

Curtain is a decision middleware for AI agents. It intercepts every action, checks it against your policies, and either approves, escalates, or blocks — in under 40ms.

01 · Query

Agent sends a plain-text action

No SDK required. One REST call — the query string is whatever your agent was about to do.

02 · Match

Hybrid vector + keyword search

Curtain matches the query against your skill corpus and returns a confidence score in <40ms.

03 · Decide

Approve, escalate, or block

Based on confidence thresholds you set. Every decision is logged to an immutable audit trail.

How it works

One API call. Full governance.

POST /api/v1/query
// 1. Agent sends an action intent POST /api/v1/query { "query": "send refund to customer #4821" } ──────────────────────────── // 2. Curtain responds in <40ms { "decision": "escalate", "skill": "process-refund", "confidence": 0.97, "escalate": true, "reason": "high-value action, review required" }

Hybrid vector + Jaccard search finds the right skill. A confidence score determines auto-approve or human review.
